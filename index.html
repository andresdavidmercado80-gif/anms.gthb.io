Clase Interactiva: Modificadores de Acceso y Encapsulamiento en C# 5

Asignatura: Programación Orientada a Objetos
Lenguaje objetivo: C# (Versión 5.0 / .NET Framework 4.5)

1. ¿Qué es el Encapsulamiento y para qué sirve?

El encapsulamiento es uno de los cuatro pilares fundamentales de la Programación Orientada a Objetos (POO). Consiste en ocultar los detalles internos de implementación de una clase y proteger el estado interno del objeto prohibiendo el acceso directo a sus variables miembro (campos).

¿Para qué sirve?

  • Control e Integridad de Datos: Previene que el código externo asigne valores no válidos o corruptos a las variables internas.
  • Flexibilidad y Mantenimiento: Permite cambiar el funcionamiento interno de una clase sin romper el código de los programas que la utilizan.
  • Seguridad: Limpia la interfaz del objeto exponiendo únicamente lo necesario para interactuar con él.

2. Modificadores de Acceso en C# 5

Los modificadores de acceso son palabras clave utilizadas para especificar la visibilidad y el alcance de los miembros (atributos, propiedades, métodos) dentro de una clase.

A. Modificador public (Público)

¿Para qué sirve? Permite acceso ilimitado. El miembro puede ser accedido desde cualquier parte del código, ya sea dentro del mismo ensamblado o desde otros proyectos que hagan referencia a él.

// Ejemplo: Método público expuesto a todo el sistema
public void MostrarInformacion()
{
    Console.WriteLine("Acceso permitido desde cualquier lugar.");
}

B. Modificador private (Privado)

¿Para qué sirve? Restringe el acceso exclusivamente al interior de la propia clase donde se declara. Es la piedra angular del encapsulamiento estricto.

// Ejemplo: Campo privado que solo la clase puede manipular directamente
private decimal _saldoCuenta;

C. Modificador protected (Protegido)

¿Para qué sirve? El miembro es accesible dentro de la clase que lo declara y dentro de cualquier clase derivada (herencia), incluso si está en otro ensamblado.

// Ejemplo: Atributo protegido usable en clases hijas mediante herencia
protected string NumeroTransaccion;

D. Modificador internal (Interno)

¿Para qué sirve? Permite el acceso desde cualquier código que forme parte del mismo proyecto o ensamblado (compilado .dll/.exe), pero no desde archivos ejecutables o bibliotecas externas.

// Ejemplo: Clase o miembro visible únicamente dentro del mismo compilado
internal class ModuloInterno
{
    internal static void Procesar() { }
}

E. Modificador protected internal (Protegido Interno)

¿Para qué sirve? Es una combinación OR: el miembro es accesible por cualquier código del mismo ensamblado O por clases derivadas en otros ensamblados.

3. Ejemplo Práctico Integrador en C# 5

A continuación se presenta el código completo en C# 5 que demuestra la aplicación del encapsulamiento (usando campos privados con propiedades de auto-implementación o getters/setters) y la interacción de los modificadores de acceso:

using System;

namespace ClaseDemostraciónCSharp5
{
    // Clase Base que representa una Cuenta Bancaria
    public class CuentaBancaria
    {
        // 1. Campo PRIVADO: Oculto para el exterior (Encapsulamiento estricto)
        private decimal _saldo;

        // 2. Campo PROTEGIDO: Accesible solo en esta clase y por sus hijas
        protected string CodigoAuditoria;

        // 3. Propiedad PÚBLICA: Controla el acceso seguro al campo privado
        public string Titular { get; private set; } // Propiedad auto-implementada de C# 5

        // Propiedad con validación lógica para garantizar integridad
        public decimal Saldo
        {
            get { return _saldo; }
        }

        // Constructor Público
        public CuentaBancaria(string titular, decimal saldoInicial)
        {
            Titular = titular;
            if (saldoInicial >= 0)
            {
                _saldo = saldoInicial;
            }
            else
            {
                _saldo = 0;
            }
            CodigoAuditoria = "AUD-" + Guid.NewGuid().ToString().Substring(0, 8);
        }

        // Método PÚBLICO para alterar el estado interno de forma segura
        public bool Depositar(decimal monto)
        {
            if (monto > 0)
            {
                _saldo += monto;
                RegistrarOperacion("Depósito de: " + monto);
                return true;
            }
            return false;
        }

        // Método PRIVADO: Auxiliar de lógica interna
        private void RegistrarOperacion(string mensaje)
        {
            Console.WriteLine("[LOG INTERNO]: " + mensaje);
        }

        // Método INTERNAL: Accesible solo dentro de este mismo proyecto/ensamblado
        internal string ObtenerReporteRápido()
        {
            return "Titular: " + Titular + " | Saldo actual: $" + _saldo;
        }
    }

    // Clase Derivada (Demuestra uso del modificador 'protected')
    public class CuentaAhorro : CuentaBancaria
    {
        public decimal TasaInteres { get; set; }

        public CuentaAhorro(string titular, decimal saldoInicial, decimal tasa) 
            : base(titular, saldoInicial)
        {
            TasaInteres = tasa;
        }

        public void ImprimirAuditoria()
        {
            // Acceso permitido al miembro PROTEGIDO de la clase padre
            Console.WriteLine("Código de Auditoría asignado: " + CodigoAuditoria);
            
            // ERROR DE COMPILACIÓN SI DESCOMENTA LA SIGUIENTE LÍNEA:
            // Console.WriteLine(_saldo); // Error: '_saldo' es PRIVADO en la clase base.
        }
    }

    // Programa Principal
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("=== DEMOSTRACIÓN DE ENCAPSULAMIENTO Y MODIFICADORES ===");

            CuentaAhorro miCuenta = new CuentaAhorro("Juan Pérez", 1000m, 0.05m);

            // Acceso a miembro PÚBLICO
            Console.WriteLine("Titular: " + miCuenta.Titular);
            Console.WriteLine("Saldo Inicial: $" + miCuenta.Saldo);

            // Intento de alteración de saldo mediante método PÚBLICO validador
            miCuenta.Depositar(500m);
            Console.WriteLine("Saldo Tras Depósito: $" + miCuenta.Saldo);

            // Acceso a miembro INTERNAL (Mismo ensamblado)
            Console.WriteLine(miCuenta.ObtenerReporteRápido());

            // Uso del método que accede a miembros PROTECTED
            miCuenta.ImprimirAuditoria();

            Console.ReadLine();
        }
    }
}

Resumen Didáctico

  • Utilice private por defecto para los datos internos de la clase.
  • Exponga los datos mediante propiedades públicas o métodos con lógica de validación para implementar correctamente el encapsulamiento.
  • Utilice protected únicamente si planea permitir que clases derivadas adapten o lean ciertos estados internos.
